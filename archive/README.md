# Archived implementation

This directory stores the implementation and tests that existed before the refactor restart.

- `apiscope/` contains the previous application source.
- `test/` contains the tests and fixtures for that source.
- The archived files are reference material only.
- The archived files are not part of the current runtime or test paths.
- The new implementation will be created under the project root.

The refactor notes are also reference material. Use the current implementation as the authority. When the implementation differs from a reference, explain the difference in a nearby code comment.
